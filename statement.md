# The Simple Grocery Store System
It is developed to simplify basic grocery shopping operations through a terminal-based Python application. The system allows users to view available items, add or remove products from a cart, manage quantities, and calculate the total bill. The project aims to provide a simple and efficient way to simulate common grocery store operations while applying fundamental Python programming concepts such as lists, functions, loops, conditional statements, and user input.
