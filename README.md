# 🛒 Simple Grocery Store System

A simple **terminal-based Grocery Store Management System** developed using Python.

This project allows a user to view available grocery items, add items to a shopping cart, view the cart, remove items, and calculate the total bill.

The project is designed as a beginner-friendly Python application to practice fundamental programming concepts such as **functions, lists, loops, conditional statements, user input, and basic calculations**.

---

## 📌 Project Overview

The **Simple Grocery Store System** simulates a basic shopping experience through the terminal.

The user can:

- View available grocery items
- Add items to the cart
- Specify the quantity of an item
- View items currently in the cart
- Remove items from the cart
- Calculate the total bill
- Exit the application

The project does not use a graphical user interface (GUI). Everything is operated through the terminal/command prompt.

---

## ✨ Features

### 1. Display Available Items

Displays all grocery items available in the store along with their prices.

### 2. Add items to cart

The user can select an item using its item number and specify the required quantity.

### 3. View cart and bill amount

Displays all items currently added to the cart along with:

Item name
Quantity
Price per item
Total price for that item

### 4. Remove items from cart

The user can remove an item that has already been added to the cart.

### How to Run
## Requirements
1. Python 3.x
2. Terminal / Command Prompt

No external Python libraries are required.

# Step 1: Clone the repository
git clone YOUR_GITHUB_REPOSITORY_LINK

# Step 2: Open the project folder
cd Simple-Grocery-Store-System

# Step 3: Run the Python program
python grocery_store.py

If your system uses python3, use:

python3 grocery_store.py
